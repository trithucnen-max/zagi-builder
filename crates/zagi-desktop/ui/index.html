Cổng AI Agent (Hermes & MCP Integration)

Hermes CLI và Claude Desktop có thể kết nối trực tiếp đến Zagi Native Rust Engine thông qua giao thức Stdio JSON-RPC 2.0.

# Lệnh chạy Zagi MCP Server trực tiếp:
zagi mcp

# Cấu hình vào ~/.hermes/config.json:
"mcpServers": {
  "zagi": {
    "command": "zagi",
    "args": ["mcp"]
  }
}
8 Công cụ MCP được hỗ trợ:
  • zagi_get_status: Báo cáo trạng thái và tài khoản kết nối.
  • zagi_list_accounts: Danh sách tài khoản Zalo.
  • zagi_get_unread_chats: Danh sách tin nhắn chưa đọc.
  • zagi_get_thread_messages: Lấy lịch sử hội thoại.
  • zagi_send_message: Gửi tin nhắn qua Zalo với Jitter & Anti-ban.
  • zagi_search_contacts: Tra cứu khách hàng CRM/danh bạ.
  • zagi_scan_phone: Kiểm tra số điện thoại có Zalo.
  • zagi_run_workflow: Kích hoạt chạy kịch bản tự động hoá.
